Thanh toán PayPal (Sandbox thật)
  1. FE chỉ gửi movieId.
  2. Backend quyết số tiền + gọi PayPal tạo order.
  3. Bạn duyệt trên popup PayPal.
  4. Backend capture + lưu Mongo collection payments.
Chưa thấy nút PayPal vì chưa dán Client ID / Secret thật.
Mở file src/main/resources/application.properties và thay: 
paypal.client-id=...Client ID Sandbox...
paypal.client-secret=...Secret Sandbox...
Lấy tại PayPal Developer Dashboard → Sandbox Apps rồi restart app.
Đăng nhập bằng buyer sandbox khi popup PayPal hiện ra. Sau khi thành công, mở trang Lịch sử thanh toán hoặc kiểm tra Mongo: use db_java_t3h_module3 → db.payments.find()
